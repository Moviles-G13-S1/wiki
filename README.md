## What This Repository Is

This repository is the team's **documentation and evidence archive** for the course. It does not contain application source code — instead it holds:

1. The **GitHub Wiki** (`/wiki` tab) — the graded, narrative write-up of each Microsprint (MS) deliverable (problem/solution description, personas, empathy maps, journey maps, VD maps, etc.), which is what gets submitted to Bloque Neón.
2. This **repo's file tree** (`main` branch) — supporting evidence and working documents referenced from the wiki: interview recordings/transcripts, deliverable checklists, and other raw materials.

The wiki pages link out to files in this repo (e.g. interview audio/video and transcripts), so the two halves work together: **wiki = polished report, repo = source evidence**.

## How Evidence Is Organized

- **Interviews:** each interview conducted for a Microsprint lives in its own `interview-N/` folder under that MS's `evidence/` directory, containing the raw recording (mp4/m4a/audio) and a full text `transcript.md`. The wiki page links back to these files rather than reproducing the raw material inline.
- **Deliverable checklists:** each MS folder has a `*_Deliverable_Checklist.md` tracking progress against the official graded requirements published by the course team for that Microsprint.
- **MS write-ups (`MS2.md`, etc.):** the drafting source for what ultimately gets published as the corresponding wiki page.

---

## Submission Rules (per course policy)

- Deliverables are graded from the **GitHub Wiki**, submitted as a link via Bloque Neón (BN) before each deadline.
- GitHub records edit timestamps in **GMT (UTC+0)**; all course deadlines are in **GMT-5**. Submissions edited after the deadline receive a grade of 0.
- MS4 (and generally, wiki deliverables) must be Markdown content in the wiki — PDF, Word, or Google Docs are not accepted as the deliverable itself.
- AI tools may be used for brainstorming, outlining, and generating ideas, but **no AI-generated content may appear in the final submission**.

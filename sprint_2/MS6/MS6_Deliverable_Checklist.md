## 2. Value Proposition

> Mandatory section. Although it is worth 0 points, if it is missing the deliverable will not be graded.

- [ ] Clearly identify the **value proposition** of the solution.
- [ ] Explain what problem or need the application addresses.
- [ ] Explain what value the application provides to users.
- [ ] Explain what makes the solution **different from existing alternatives**.
- [ ] Make the application's main differentiating factor clear.

---

## 3. UI/UX Design

### 3.1 Colour Palette

- [ ] Define the application's main colour palette.
- [ ] Include the selected colours.
- [ ] Include the HEX/RGB values of the colours.
- [ ] Explain the **rationale behind the colour palette**.
- [ ] Explain how the colours relate to the identity and purpose of the application.
- [ ] Ensure sufficient contrast and readability.

---

### 3.2 Fonts

- [ ] Define the font or fonts that will be used.
- [ ] Define their use for:
  - [ ] Titles
  - [ ] Subtitles
  - [ ] Body text
  - [ ] Buttons / labels
- [ ] Show examples of the selected typography.
- [ ] Maintain typographic consistency throughout the application.

---

### 3.3 Icons and Images

- [ ] Define the style of icons used in the application.
- [ ] Show examples of the main icons.
- [ ] Explain where the icons will be used.
- [ ] Define the style/type of images used in the application.
- [ ] Ensure icons and images follow a consistent visual style.
- [ ] Use clear and sufficiently high-resolution visual resources.

---

### 3.4 UI Prototype

- [ ] Create the UI prototype of the application.
- [ ] Include the application's main screens/views.
- [ ] Show the most important user interactions.
- [ ] Make sure the prototype reflects the defined:
  - [ ] Colour palette
  - [ ] Typography
  - [ ] Icons
  - [ ] Images
- [ ] Include clear screenshots/images of the prototype in the wiki.
- [ ] Make sure all prototype images are legible and high resolution.
- [ ] Include a link to the interactive prototype if available.

---

### 3.5 Navigational Patterns

- [ ] Define the main navigation pattern of the application.
- [ ] Explain how users move between the main screens.
- [ ] Identify the navigation components used, for example:
  - [ ] Bottom navigation bar
  - [ ] Navigation drawer
  - [ ] Tabs
  - [ ] Back navigation
  - [ ] Buttons / cards
- [ ] Explain why the selected navigation pattern is appropriate for the application.
- [ ] Show the navigation flow between the main screens.
